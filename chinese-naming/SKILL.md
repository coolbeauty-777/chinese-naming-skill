# 中文起名（八字五行 + 康熙五格）

这是一套传统姓名学的规则体系。按它的规则认真执行并讲清依据，但不替它背书：不要说"保证""注定""一定改变命运"，评语是各流派的经验性说法，要让用户能看出每个结论从哪来。

排盘、笔画、五格、筛字全部交给脚本计算，不要心算（模型很容易算错康熙笔画）。字义、音律、寓意、重名和整体美感由你判断。

## 工作流

**0. 输入越简单越好**：只需要姓氏、性别、出生日期和时间（公历或农历都行），外加**出生地**（城市即可，用来校正真太阳时，所以开头就问一下）。用户不知道或不想给出生地，就按钟表时间排盘，并在思路里注明。名字几个字没说就单名双名都给；字辈、风格等用户没提就不要追问。用户如果已经有喜用神（来自其他排盘软件），直接用，跳过第 1、2 步。用户如果只是想评价一个已有的名字，直接跳到第 5 步。

**1. 排八字**

```bash
python scripts/bazi.py --lunar 1995-3-15 --time 10:20 --gender 女 --place 成都   # 农历（闰月加 --leap）
python scripts/bazi.py --date 2026-03-15 --time 08:30 --gender 男 --lon 116.4    # 公历, 城市不在表内时直接给经度
```

**出生地为什么重要**：钟表用的是北京时间（东经 120° 的时间），出生地与它每差 1° 经度就差 4 分钟，再加上随季节变化的均时差，就是"真太阳时"。它主要影响时柱，出生时间在时辰交界附近时还可能影响日柱（临近 23:00）甚至月柱（临近节气）。另外，中国大陆 1986–1991 年实行夏令时，钟表时间要先减 1 小时，脚本会自动处理。

给了出生地，脚本会同时排"钟表时间"和"真太阳时"两个盘，并指出哪一柱不同。处理方式：

- **四柱一致**：写一句"出生地不影响本盘"即可。
- **四柱不同**：两个盘都写出来，分别判断旺衰。喜用神结论一致就说明"不影响起名"；不一致时以真太阳时为主、钟表时间为辅（多数流派用真太阳时，也有人只用钟表时间），把差异讲清楚。
- **校正后的时间距时辰交界不到 10 分钟**（脚本会提醒）：向用户确认出生地和时间，尽量精确到分钟。
- 农历日期会先换算成公历，把换算结果写进思路里；晚子时（23:00–24:00）出生要说明排盘口径。

输出还有四柱、日主、五行统计、月令和"旺衰参考"。

**2. 定喜用神（你来判断，并说明理由）**

旺衰参考分只是启发式的，要结合全盘看：日主得不得令（月令权重最大）、生扶与克泄耗的力量对比、是否过寒过燥需要调候、是否有通关需要。大致原则：日主偏弱，以生扶（印、比劫）为喜；日主偏强，以克泄耗（官杀、财、食伤）为喜。遇到从格、专旺等特殊格局，说明这是需要专业判断的情形，不要装作确定。给出主要喜用神 1–2 个五行和次要的，并说明"不同流派取法可能不同"。不要简单地"缺什么补什么"，缺失的五行只是参考之一。

**3. 列出筛选后的选项（少而精，先摆出选择空间，不要先推荐名字）**

```bash
python scripts/list_options.py --surname 王 --gender 女 --elements 水,木 --len both --chars-level 1
```

脚本按"分层递补"筛选笔画组合，目标是组合少而清晰，不要让用户看花眼：

- **硬条件**：人格、总格必须是稳吉数；女性不用 21、23、33、39 作人格、总格、地格。
- **地格**：尽量吉；只有"地格吉、外格不凶"的组合太少（双名少于 6 个，单名少于 3 个）时，才按层补充"地格半吉"的，再不够才放外格凶的；**地格凶的一律不列**。
- **外格**：只大概看，组合够多时外格凶的不列。
- **可选字太少的组合不列**：某个笔画下喜用神五行的可选字少于 10 个（多为生僻难写的字）。
- 天格对单姓固定，不计。

脚本依次输出，请完整呈现，不要用"若干""约几十个"替代：

1. **吉数**：直接写出稳吉数具体是哪些（三份资料评语都是吉的数），并说明筛选规则。不要只说"排除了多少个"。
2. **筛选后的笔画组合**：按层分组的表格，列出人格、地格、外格、总格、三才和三才关系，以及每个位置的可选字数；说明有没有递补、为什么。末尾一行写明未列出了哪些（地格凶多少个等）。
3. **建议的笔画组合**：脚本给出的前几名；你要在其后用 2–4 句话做**小结**：首选哪个、为什么，次选哪个、有什么需要留意（如外格是女性不宜数、笔画偏繁），不建议哪个。
4. **按笔画列出的可选字**：只列上面组合用到的笔画，按喜用神五行分别列出具体的字。一级常用字放进聊天；二级字另存文件（`--chars-level 2 > 文件.md`，再用 present_files 交付）。脚本只剔除明显不宜入名的字，并列出被剔除的字；**不按"是否常见名用字"过滤**。

**4. 用户自己选字**：字表和组合表都给出来之后，用户可以自己组合。这时才由你补充推荐。

**5. 推荐（放在最后）**：从建议的笔画组合和字表里挑 5–8 个，逐个检查字义、音律（声调错落、顺口）、谐音（连读有无不雅）、字形、搭配和时代感；用中文解释寓意，注明用了哪个笔画组合。自拟或从字表组合出的名字，都先用下面命令回填五格再给用户：

```bash
python scripts/wuge.py --surname 王 --given 希月
```

字不在字库时会报错，说明是非通用规范汉字或太生僻，要换字或告知用户。

如果只是想要一批随机候选而不需要完整列表，可以用 `scripts/pick_names.py`（按名用字频次和性别倾向筛选，参数见 `--help`）。

**6. 输出结构**：按下面五节写，每节先结论再依据，思路必须完整，用户说"简单点"时缩短的是每节的说明文字，不是删掉列表：

1. 八字：四柱、日主（农历要写出换算后的公历）
2. 喜用神：旺衰怎么判断的，取哪个五行，为什么
3. 笔画与五格：吉数是哪些、筛选规则；筛选后的笔画组合；建议的组合和小结
4. 可选的字：只列建议组合用到的笔画，按五行列出具体的字（一级字在聊天里，二级字在文件里）
5. 推荐：每个名字注明笔画组合、五格、五行、寓意；如实标出评语有分歧的数、笔画未能核验的字

最后一行提示夏令时或节气交接等情况（如适用）。

## 采用的规则（简版，详见 references/methodology.md）

- **笔画**：全部用康熙笔画，简体字按其对应的繁体字形计算（氵算 4 画，艹算 6 画，辶算 7 画）。姓氏和"本字也是康熙字典独立字"的字取本字：于 3、余 7、姜 9、朱 6、胡 11、沈 8。**王是 5 画**：《康熙字典》原文注明归玉部、部外 0 画，玉部首 5 画，不是书写的 4 画。凡原文自带"康熙笔画"标注的字，一律以原文为准。
- **五格**：单姓天格加 1，单名地格加 1；单姓单名外格为 2，此时人格和总格相同；总格超过 81 减去 80；数理五行按末位（1、2 木，3、4 火，5、6 土，7、8 金，9、0 水）。
- **硬条件**：人格和总格必须"稳吉"（所有来源和版本都评为吉，共 25 个数）。天格对单姓是固定的，不计。女性另外排除人格、总格、地格里的"女性不宜"数：21、23、33、39。
- **软条件**：地格、外格不凶，三才相生更好。
- **有争议的数**：9、10、19、27、29、36、39、40、42、49、50、51、55、71、72、75、78，各来源评语分歧大，出现时必须标明。
- **汉字五行**：这是一种约定，没有权威标准。字库里的五行来自 shunshi-kangxi-core 的标注，少量缺标注的字按部首规则推断（`wx_src` 为 `radical_rule`），无法判断的不参与按五行的筛选。同一个字在不同软件里五行可能不同（比如"明"在这张表里是水，按声母的五音算），如果用户质疑，如实说明这是约定。
- **笔画可靠度**：笔画以《康熙字典》为准，字库里每个字有证据等级（`evidence` 列）：A 原文自带标注，B 原书正文页位核验，C 原书页位核验（原书用异体字形），D 只有多个来源一致、没能在原书核验（字表里标 †），X 本字与繁体字形笔画不同、需要取舍。约 97.8% 的字是 A、B、C。`narrowed` 表示可能有 ±1 的误差；`policy_dual` 表示本字与繁体字形不同。脚本默认不挑这两类字；分析自拟名字时遇到 †、D、X 的字要如实提示用户核对。**不要凭记忆改笔画**，有疑问以 `chars.csv` 和原书为准，并告诉用户依据。

## 局限，必须如实告知用户

- 字库只含 8105 个通用规范汉字（中国大陆姓名可用字范围）。
- 用字频次来自一份公开人名语料，偏向较早年代的名字；它只用于 pick_names.py 的筛选，以及字表里 ♂ 标记（该字在真实人名里明显偏男性使用）。
- 传统姓名学没有统一标准，换一套数理表或五行表，结论会不同。
- 以上都是文化传统中的经验规则，不是科学结论。
